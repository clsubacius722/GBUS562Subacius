# Assignment: Week 02

Prompt engineering with the [Prompt Lab](../prompt-lab.html), a web app for testing prompts against Claude, built with Claude Code.

## Focus

A good prompt has five elements:

1. **Role:** who the model should be
2. **Context:** background it needs
3. **Task:** what to do
4. **Form:** the shape of the output
5. **Constraints:** limits and rules
