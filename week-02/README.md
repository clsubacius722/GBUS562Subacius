## Prompt Lab

A single-page web app for writing prompts and sending them to Claude. Open `prompt-lab.html` in any web browser, paste your Anthropic API key into the API key field (it is never saved), add an optional system prompt, and send prompts. The whole conversation is sent with each new prompt.
